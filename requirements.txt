# WhisperX orchestre Whisper, l'alignement mot à mot et pyannote sur le pod.
# Les versions sont verrouillées : toute mise à jour CUDA/Torch se fait dans
# une PR dédiée, validée par la construction de l'image RunPod.
#
# torch et torchaudio sont épinglés ensemble. Pyannote 3.3.2 ne définit que
# des bornes minimales, mais son import dépend encore de ``AudioMetaData`` :
# cette API n'est plus présente dans torchaudio 2.11. Le Dockerfile installe
# explicitement les roues CUDA 12.1 correspondantes depuis PyTorch avant ce
# fichier ; les versions ci-dessous empêchent pip de les remplacer ensuite.
torch==2.5.1
torchaudio==2.5.1
whisperx==3.3.2
# torch 2.5.1 installe nvidia-cudnn-cu12 9.1 (cuDNN 9). whisperx 3.3.1
# épinglait ctranslate2<4.5.0 (donc 4.4.x), qui exige cuDNN 8 — absent de
# l'image, d'où un crash natif « Could not load library
# libcudnn_ops_infer.so.8 » qui tue le processus (pas une exception Python)
# et fait redémarrer le conteneur. whisperx 3.3.2 a les mêmes dépendances
# sauf ctranslate2>=4.5.0, qui utilise cuDNN 9 : épingler cette version ici
# explicitement pour ne pas dépendre du minimum transitif de whisperx.
ctranslate2==4.5.0
pyannote.audio==3.3.2
# pyannote 3.3.2 importe matplotlib à l'initialisation mais ne le déclare
# pas dans ses dépendances publiées.
matplotlib>=3.7,<4
# pyannote 3.3.2 ne déclare que huggingface_hub>=0.13 mais appelle encore
# hf_hub_download(..., use_auth_token=...), un argument que huggingface_hub
# 1.0 a supprimé (remplacé par `token`). Sans borne haute, pip installait
# la 1.x et la diarisation échouait à la première transcription :
# « hf_hub_download() got an unexpected keyword argument 'use_auth_token' ».
# C'est transformers (non épinglé par whisperx) qui tirait la 1.x : ses
# versions 5.x exigent huggingface_hub>=1.3, ses 4.5x huggingface_hub<1.0.
# Les deux bornes vont donc ensemble ; borne basse de hub : celle de
# transformers 4.56+ (et hf_xet, ci-dessous, n'est utilisé qu'à partir de
# la 0.30).
transformers>=4.48,<5
huggingface_hub>=0.34,<1.0
# Backend de transfert accéléré de huggingface_hub (téléchargement des
# modèles Whisper) : sans lui, HF_XET_HIGH_PERFORMANCE (voir handler.py /
# pod_server.py) n'a aucun effet et on retombe sur un simple GET HTTP.
hf_xet>=1.0
