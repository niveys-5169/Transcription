    En bref

      Le WAV 16 kHz mono effectivement envoyé au moteur. S'il est muet, le problème vient de l'extraction, pas de la transcription.

      Réglages

      Accès à Claude

      Sert à la relecture, au sommaire et à la vérification par recherche web. Deux façons d'y accéder : le CLI claude, sur votre abonnement (recommandé — installez Claude Code et lancez claude setup-token une fois) ; ou une clé API Anthropic, facturée séparément à l'usage.

      Vérification externe (recherche web)

      Après la relecture, une recherche web ciblée vérifie les noms propres, titres de rapport, statistiques et références juridiques cités — pas une simple relecture de plausibilité. Ce qui n'a pas pu être confirmé reste visible dans le texte, avec un appel de note : rien n'est lissé en une version fluide mais faussement définitive.

      Lexique MJPM

      Sigles, acteurs, actes et références juridiques du domaine (MJPM, DIPM, CRG, curatelle renforcée…). Sert à amorcer la reconnaissance vocale, à repérer une graphie proche mais douteuse, et à résoudre certains points sans recherche web pour les termes déjà vérifiés.

      Coffre Obsidian

      Chemin d'un coffre existant sur cette machine. La fiche y est écrite directement, dans le dossier indiqué ; les fiches d'entités et le glossaire suivent la même logique — voir le README pour le détail de la convention.

      RunPod (GPU dans le cloud, optionnel)

      Utile pour les cours longs en large-v3 quand le processeur devient trop lent. Le fichier est découpé sur des silences avant l'envoi.

      Pod RunPod (avancé, optionnel)

      Un pod est une machine GPU louée à la minute (pas à la requête comme le serverless), créée puis détruite pour chaque transcription qui en a besoin. Nécessite une image Docker poussée séparément (voir le README) : le serverless se construit seul depuis ce dépôt, pas un pod.
