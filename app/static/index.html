    En bref

      Le WAV 16 kHz mono effectivement envoyé au moteur. S'il est muet, le problème vient de l'extraction, pas de la transcription.

      Réglages

      Relecture par Claude

      La relecture transforme le flot de paroles en texte ponctué et structuré. Sans clé, l'application se rabat automatiquement sur la relecture simple, qui fonctionne hors ligne.

      RunPod (GPU dans le cloud, optionnel)

      Utile pour les cours longs en large-v3 quand le processeur devient trop lent. Le fichier est découpé sur des silences avant l'envoi.

      Pod RunPod (avancé, optionnel)

      Un pod est une machine GPU louée à la minute (pas à la requête comme le serverless), créée puis détruite pour chaque transcription qui en a besoin. Nécessite une image Docker poussée séparément (voir le README) : le serverless se construit seul depuis ce dépôt, pas un pod.
